1 用 Qt Creator 打开项目

① 找到 Qt Creator 并启动
打开文件资源管理器，进入路径：
E:\Qt\Tools\QtCreator\bin\qtcreator.exe
双击 qtcreator.exe 启动 Qt Creator。
② 通过菜单打开项目
启动后，点击顶部菜单栏：
文件(File) → 打开文件或项目...(Open File or Project...)
快捷键：Ctrl + O
③ 选择工程文件
在弹出的文件浏览窗口中，导航到：
E:\Qtwork\test\Calculator\Calculator.pro
选中 Calculator.pro 文件，点击 打开(Open)。
如果 Qt Creator 弹出 "Configure Project"（配置项目）界面，说明项目已成功打开，请继续下一步。

2 配置编译套件 (Kit)

首次打开项目时，Qt Creator 会让你选择编译套件。你的电脑上已安装以下套件：

① 在配置界面勾选套件
在 "Configure Project" 界面中，你会看到一个列表，类似：
☐ Desktop Qt 5.12.11 MinGW 64-bit
☐ Desktop Qt 5.12.11 MinGW 32-bit
☐ Desktop Qt 5.12.11 MSVC 2017 64-bit
勾选 "Desktop Qt 5.12.11 MinGW 64-bit"（推荐使用 64 位版本）。
② 点击配置按钮
在界面下方点击 Configure Project 按钮。
Qt Creator 会自动生成构建配置。
③ 如果没有弹出配置界面
说明之前已配置过。你可以在左侧栏点击 Projects（项目图标 ⚙），
在 "Build & Run" 中确认已选中 MinGW 64-bit 套件。
如果列表中没有任何套件可选，说明 Qt 安装不完整。需要运行 E:\Qt\MaintenanceTool.exe 重新安装编译器组件。

① 找到 UI 文件
在 Qt Creator 左侧栏点击 Edit（编辑模式）。

4 编译并运行项目

① 选择构建模式
在 Qt Creator 左下角，确保模式选择为 Release（发布模式）。
点击左下角的模式选择器（通常显示 "Debug" 或 "Release"），选择 Release。
Debug: 便于调试，但生成的程序体积较大 Release: 优化编译，程序更小更快，推荐使用
② 编译项目
点击菜单：构建(Build) → 构建项目 "Calculator"(Build Project "Calculator")
快捷键：Ctrl + B

在底部 "编译输出(Compile Output)" 窗口可以看到编译进度。
如果显示 "exited normally" 且没有红色错误，说明编译成功！
③ 运行项目
点击左下角的绿色三角形 ▶ 按钮 运行(Run)
快捷键：Ctrl + R

计算器窗口将会弹出，深色主题界面，显示初始值 "0"。
也可以直接使用快捷键 Ctrl + R 一步完成"编译 + 运行"，不需要先单独编译。

5 测试计算器功能

计算器同时支持鼠标点击和键盘输入两种方式，且共用同一套处理逻辑。以下是完整的测试清单：

① 鼠标测试 — 基本四则运算
  • 点击 5 → 显示 "5"
  • 点击 + → 上方历史显示 "5 +"，显示屏仍为 "5"
  • 点击 3 → 显示 "3"
  • 点击 = → 历史显示 "5 + 3 ="，结果显示 "8"
  • 点击 C → 全部清空，显示屏回到 "0"
② 鼠标测试 — 小数运算
  • 点击 1 → 2 → . → 5 → 显示 "12.5"
  • 点击 × → 历史显示 "12.5 ×"
  • 点击 2 → 显示 "2"
  • 点击 = → 结果显示 "25"
  • 点击 C 清空
③ 键盘测试 — 全键盘操作
  • 按键盘 7 → 显示 "7"
  • 按 - (减号键) → 历史显示 "7 −"
  • 按 3 → 显示 "3"
  • 按 Enter 或 = → 结果显示 "4"
④ 键盘映射对照表
键盘按键对应功能等同于按钮
0 ~ 9输入数字btn0 ~ btn9
. (句号)输入小数点btnDecimal
+ (Shift+=)加法btnAdd
- (减号)减法btnSubtract
* (Shift+8)乘法btnMultiply
/ (斜杠)除法btnDivide
Enter / =等于btnEquals
Backspace退格删除btnBackspace
Esc / Delete清除btnClear
小键盘(Numpad)上的数字键、+、-、*、/、Enter 同样有效！
⑤ 边界情况测试
  • 连续小数点：输入 5 → . → . → 应只显示 "5."，第二个点被忽略
  • 连续操作符：输入 5 → + → × → 应显示 "5 ×"（后按的运算符替换前者）
  • 除零：输入 5 → ÷ → 0 → = → 显示 "Error: ÷ 0"
  • 退格：输入 123 → ⌫ → 显示 "12"
  • 连续运算：输入 5 → + → 3 → - → 2 → = → 显示 "6"（先算5+3=8，再算8-2=6）
  • 计算后继续：5 + 3 = 8 → 按 2 → 显示 "2"（开始新计算）
  • 混合输入：鼠标点击 5 → +，键盘按 3 → = → 结果 "8"
  • 无第二操作数：5 + = → 结果 "10"（自动复用第一操作数）

6 使用 Git 管理代码（作业要求）

作业要求用 GitHub 管理代码，至少 5 次有效提交。以下是操作步骤：

① 初始化本地 Git 仓库
打开终端（PowerShell 或 Git Bash），进入项目目录：
cd E:\Qtwork\test\Calculator git init
② 创建 .gitignore 文件
在项目目录下创建 .gitignore 文件，内容如下：
# 构建产物 build/ release/ debug/ *.o *.obj *.exe # Qt 生成文件 ui_*.h moc_*.cpp qrc_*.cpp Makefile Makefile.* .qmake.stash # 用户配置 *.user *.user.* .vscode/
③ 首次提交
git add . git commit -m "feat: 完成计算器基础框架与UI布局"
④ 关联 GitHub 远程仓库
在 GitHub 上创建一个新仓库（如 qt-calculator），然后：
git remote add origin https://github.com/你的用户名/qt-calculator.git git branch -M main git push -u origin main
⑤ 持续提交（模拟开发迭代）
每次修改代码后，提交一次，展示开发过程：
git add . git commit -m "fix: 修复连续小数点输入问题" git push # 之后继续： git commit -m "feat: 添加键盘事件处理" git commit -m "fix: 处理除零异常" git commit -m "style: 优化深色主题样式表" git commit -m "docs: 添加代码注释与说明"
Git 提交信息建议使用约定式格式：feat:(新功能)、fix:(修复)、style:(样式)、docs:(文档)。

7 项目文件结构说明

Calculator/ ├── Calculator.pro ← Qt工程文件，告诉qmake如何编译 ├── main.cpp ← 程序入口，创建并显示主窗口 ├── mainwindow.h ← 主窗口类声明（状态变量+槽函数） ├── mainwindow.cpp ← 核心逻辑（四则运算+键盘事件+边界处理） ├── mainwindow.ui ← UI界面文件（按钮布局+控件属性） ├── 操作指南.html ← 本指南 └── release/ └── Calculator.exe ← 编译生成的可执行程序

各文件的职责：

Calculator.pro — 工程配置文件。声明了使用的 Qt 模块（core/gui/widgets）、源文件列表、头文件列表和 UI 文件。

mainwindow.ui — XML 格式的界面定义文件。包含主窗口布局：显示屏 + 历史标签 + 18 个按钮的网格布局。双击可在 Qt Creator 设计器中可视化编辑。

mainwindow.h — 类声明。定义了计算器状态变量（m_firstOperand、m_pendingOperator、m_waitingForOperand、m_error）、按钮槽函数和统一处理方法。

mainwindow.cpp — 核心实现。包含信号槽连接、深色主题样式表、四则运算逻辑、键盘事件处理、异常输入处理等全部功能代码。

main.cpp — 程序入口。创建 QApplication 和 MainWindow 实例，进入事件循环。

8 常见问题排查

Q: 编译时报错 "cannot find -lQt5Core"？
A: 检查是否正确选择了 MinGW 64-bit 套件。在左侧 Projects 面板中确认 Build 套件。
Q: 运行后窗口一闪而过？
A: 检查控制台输出是否有运行时错误。确保在 Release 模式下构建。也可以尝试 Debug 模式查看详细错误。
Q: 按钮上的 ÷ × − 显示为方框？
A: 这是字体不支持 Unicode 数学符号导致的。在设计器中选中按钮，在属性编辑器中将 font 改为 Segoe UI Symbol 或 Microsoft YaHei。
Q: 键盘按键无反应？
A: 确保计算器窗口处于焦点状态（用鼠标点击一下窗口任意位置使其获得焦点）。keyPressEvent 只在窗口有焦点时触发。
Q: 想修改按钮颜色或样式？
A: 样式在 mainwindow.cpp 的 applyStyleSheet() 方法中定义。找到对应的 QPushButton#btnXxx 选择器修改颜色值即可。
Q: 如何在 Qt Creator 中调试代码？
A: 切换到 Debug 模式 → 在代码行号左侧点击设置断点(红点) → 按 F5 启动调试。程序会在断点处暂停，可以查看变量值。
